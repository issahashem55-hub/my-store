# متجر أبو الأكبر الجيسي — دليل الاستخدام

هذا دليل بسيط يشرح لك خطوة بخطوة كيف تشغّل متجرك وتديره من جوالك، بدون الحاجة لأي خبرة برمجية.

---

## 1️⃣ رفع الملفات على GitHub

1. افتح موقع [github.com](https://github.com) وسجّل دخولك (أو أنشئ حساباً جديداً مجاناً).
2. اضغط على **+** أعلى الصفحة ثم **New repository**.
3. اختر اسماً للمستودع، مثلاً: `abo-alakbar-store`.
4. اجعله **Public**.
5. اضغط **Create repository**.
6. داخل المستودع، اضغط **Add file → Upload files**.
7. ارفع الملفات الثلاثة:
   - `index.html`
   - `apps.json`
   - `README.md`
8. اضغط **Commit changes** لحفظها.

---

## 2️⃣ تفعيل GitHub Pages

1. داخل المستودع، اذهب إلى **Settings**.
2. من القائمة الجانبية اختر **Pages**.
3. تحت **Branch** اختر `main` والمجلد `/ (root)`.
4. اضغط **Save**.
5. انتظر دقيقة أو اثنتين، وسيظهر لك رابط الموقع بالشكل:
   ```
   https://اسم_المستخدم.github.io/abo-alakbar-store/
   ```
6. هذا هو رابط متجرك الدائم — شاركه مع من تريد.

---

## 3️⃣ تعديل `apps.json` من جوالك (خطوة بخطوة)

1. افتح تطبيق **GitHub** على جوالك (متوفر لأندرويد وآيفون)، وسجّل دخولك بنفس الحساب.
2. ادخل إلى المستودع الخاص بك.
3. اضغط على ملف `apps.json`.
4. اضغط على أيقونة **القلم ✏️** أعلى الصفحة للتعديل.
5. عدّل النص كما تريد (أضف تطبيقاً، أو غيّر رابطاً، أو صحّح وصفاً).
6. انزل للأسفل واضغط **Commit changes**.
7. بعد دقيقة تقريباً، ستنعكس التعديلات تلقائياً على موقعك المباشر.

⚠️ **مهم:** ملف `apps.json` يجب أن يبقى بصيغة JSON صحيحة (أقواس مغلقة، فواصل صحيحة). إذا أخطأت في كتابته، قد يتوقف الموقع عن عرض التطبيقات. يمكنك التأكد من صحة الملف عبر لصقه في موقع [jsonlint.com](https://jsonlint.com) قبل الحفظ.

---

## 4️⃣ رفع صور التطبيقات إلى مجلد `images/`

1. داخل المستودع، اضغط **Add file → Create new file**.
2. اكتب اسم الملف بالشكل: `images/app-1.png` (كتابة `images/` قبل الاسم تنشئ المجلد تلقائياً).
3. بدلاً من كتابة محتوى، اضغط على تبويب **Upload files** الذي يظهر فوق صندوق الكتابة، واسحب صورتك.
4. كرر نفس الخطوة لكل صورة (أيقونة التطبيق، ولقطات الشاشة).
5. تأكد أن اسم الصورة في `apps.json` يطابق تماماً اسم الملف الذي رفعته (بما في ذلك حالة الأحرف الكبيرة والصغيرة).

مثال لمسارات الصور داخل `apps.json`:
```json
"icon": "images/app-1.png",
"screenshots": [
  "images/app-1-shot-1.png",
  "images/app-1-shot-2.png"
]
```

📌 إن لم تُرفع الصورة أو كان اسمها غير مطابق، سيعرض الموقع تلقائياً حرفاً ذهبياً بدلاً منها (لا يحدث أي خطأ ظاهر للزائر).

---

## 5️⃣ إضافة تطبيق جديد (نموذج جاهز)

افتح `apps.json`، وأضف كتلة جديدة داخل مصفوفة `"apps"` (لا تنسَ الفاصلة `,` بعد الكتلة السابقة):

```json
{
  "id": "app-4",
  "name": "اسم التطبيق الجديد",
  "description": "وصف كامل للتطبيق ووظيفته.",
  "icon": "images/app-4.png",
  "screenshots": [
    "images/app-4-shot-1.png"
  ],
  "size": "40 MB",
  "version": "1.0.0",
  "rating": 4.7,
  "category": "أدوات",
  "features": [
    "ميزة أولى",
    "ميزة ثانية"
  ],
  "mediafire": "رابط_الميديافاير_هنا",
  "mega": ""
}
```

- إن لم يكن لديك رابط Mega، اتركه فارغاً `""` وسيختفي زر Mega تلقائياً من صفحة التطبيق.
- حقل `"category"` يظهر تلقائياً كقسم جديد في شريط الأقسام أعلى المتجر.

---

## 6️⃣ رفع ملف APK على MediaFire والحصول على الرابط

1. افتح [mediafire.com](https://www.mediafire.com) وسجّل دخولك أو أنشئ حساباً مجانياً.
2. اضغط **Upload** واختر ملف الـ APK من جهازك.
3. بعد انتهاء الرفع، اضغط على الملف ثم اختر **Share → Copy link**.
4. الصق هذا الرابط في حقل `"mediafire"` الخاص بالتطبيق داخل `apps.json`.

---

## 7️⃣ تحديث بيانات تطبيق موجود

1. افتح `apps.json` من تطبيق GitHub على جوالك.
2. اضغط ✏️ للتعديل.
3. ابحث عن التطبيق المطلوب باسمه أو بـ `"id"` الخاص به.
4. عدّل أي حقل تريده (الاسم، الوصف، الحجم، الإصدار، الرابط...).
5. احفظ عبر **Commit changes**.
